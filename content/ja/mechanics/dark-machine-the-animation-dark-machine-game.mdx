## アニメがメカニクスをドラマに変える方法

ここが、Dark Machine The AnimationとDARK MACHINE THE GAMEの関係が本当に面白くなる点です。eスポーツを題材にしたアニメには構造的な問題があります。誰かがボタンを押しているのを見るのは退屈だということです。この作品は、メカニクスをキャラクター描写として扱うことでそれを解決します。

- **クラス選択がアイデンティティになる。** パイロットの役割は、彼らが口を開く前に、彼らが誰なのかを語ります。
- **7v7形式が群像劇のエンジンになる。** 7人のプレイヤーは、7つの人格、7つの遺恨、そしてヴィランとは無関係にチーム内の摩擦が生まれる理由を意味します。
- **Senkiの称号が頂点になる。** 漠然とした「世界最強」というラベルではなく、作品はランクの頂点に名前を与え、そして標的を与えます。

| メカニクス | 画面上では | ゲーム内では |
|---|---|---|
| マシンカスタマイズ | パイロットの人格を表す視覚的な記号 | キットを変えるビルド選択 |
| 3つの戦闘クラス | ロールの変化を軸にしたキャラクターアーク | マシンの成長パス |
| 7v7チームプレイ | 個性ある声と内部対立を抱えた部隊 | ロール補完を求めるマッチメイキング |
| Senkiの称号 | すべてのライバルが目指す物語上の頂点 | アニメの演出上の枠組みであり、ゲーム内ランクとして確認されたものではない |
| アリーナマッチ | 明確な勝利条件を持つセットピースの戦い | 反復可能なPvPラウンド |

最後の行は繰り返す価値があります。Senkiの称号はドラマ上の目的でアニメが生み出したものです。ゲームが正式なランクでそれを再現しているかどうかは、入手可能な資料では確認できません。そのため、インストールした瞬間に「Senki」バッジが手に入るとは期待しないでください。

## よくある質問

**『Dark Machine The Animation』は実在のゲームが原作ですか？**
はい。PCとコンソール向けに予定されている実際のプレイアブルタイトル、[SteamのDARK MACHINE THE GAME](https://store.steampowered.com/app/4406410/DARK_MACHINE_THE_GAME/)を含むメディアミックス企画の一部です。Dark Machine The AnimationとDARK MACHINE THE GAMEの企画は、ひとつのプロパティの2つの半分として設計されており、だからこそ両者の用語はこれほどきれいに対応するのです。

**アニメを追うのにゲームをプレイする必要はありますか？**
いいえ。アニメは自らのルールを説明します。eスポーツ、Senkiの称号、そして賭けられているものはすべて作中で紹介されます。ゲームをプレイすると、試合シーンの裏にある判断が分かるため、見え方が変わるだけです。

**戦闘クラスはいくつありますか？**
3つです。カスタムマシンは3つの戦闘クラスを通じて進化し、アニメはキャラクターに部隊内で異なる役割を与える際にその構造を活用しています。

**どこで視聴でき、どこでプレイできますか？**
アニメは[CrunchyrollのDark Machine The Animationシリーズページ](https://www.crunchyroll.com/series/GT00383997/dark-machine-the-animation)で配信されており、フジテレビが公式プロジェクトページをホストしています。ゲームはSteamに掲載されており、PCとコンソールのプラットフォームが予定されています。

視聴者として来た人もプレイヤーとして来た人も、共通するのはメカニクスです。クラス、7v7形式、Senkiのランクがどう噛み合うかが分かると、どちらの半分も以前とはまったく同じには見えなくなります。
